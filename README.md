## `03 // HOW I BUILD`

```text
signal
  ↓
data / documents / events
  ↓
filter · retrieve · rank · model
  ↓
validate · evaluate · guard
  ↓
API / product / automation
  ↓
measure → learn → iterate
```

My default question is not *“Can a model do this?”*

It is **“Can we make it useful, measurable, reliable, and cheap enough to keep running?”**
